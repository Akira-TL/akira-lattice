# 文章与论文的直接表达

本文件补充核心提示词中的直接表达规则。起草、修改和定稿时按相关部分执行；只改一段时，处理该段涉及的内容即可。输出语言按用户指定，未指定时沿用原稿语言。

## 核心写法

直接说清文章的观点：事实是什么，文章提出了什么观点，证据表明什么，方法能做什么。用平静、专业的语气把观点和理由讲清楚。

先说观点，一段说清一件事。直接说明文章研究、解释、检验、比较或贡献了什么。概念不清就解释概念，理由不足就补充已有证据或理顺推理，结论过大就缩小范围。需要区分两种观点或解释差异时，再使用对比。

## 必要限定

省略某项限定会影响观点是否成立、如何理解证据、结论适用范围、研究设计，或读者能否正确使用结果时，应清楚说明。伦理、法律和安全要求所需的限定也应保留。

必要的限制通常放在方法、讨论或局限部分。摘要、引言、贡献段落、段首句和结论中的限定，以该处准确表达所需为准；同一限制避免反复强调。某句话离开限定就会误解时，在该句保留限定。

## 修改流程

1. 判断句子为什么要写，分清不必要的免责声明、必要的范围限定、真实的方法局限、有助于论证的概念区分、根据证据作出的必要限定和重复澄清。
2. 删除既不提供证据，也不说明范围、推进论证、澄清概念或帮助理解的句子。
3. 直接说明研究范围，把措辞校准到证据支持的程度。确有不确定性时，说明它来自哪里。
4. 围绕段落观点重新组织：开头说清观点，一段围绕一件事，前后顺序合理，删改重复限制、道歉式表达及无助于全文论证的内容。

例如，研究范围可写为“本文分析了 2015 至 2023 年的城市治理案例”。证据支持的关系可写为“证据表明，在这些案例中，X 会影响 Y”。确有推断范围限制时，可写为“现有证据支持这一解释，但尚不能据此估计总体效应”。以上表述均须有原稿依据。

## 句式与示例

优先使用能直接交代内容的句式：“本文研究……”“本研究表明……”“本文重点分析……”“证据表明……”“该设计可以……”“结果提示……”“主要贡献在于……”“本节解释……”“下文分三步论证……”“在这些条件下，X 通过……影响 Y。”按证据选择动词和确定程度。

除非删去会影响准确性，否则删改以下句式：“本文并不声称……”“我们并不试图……”“这并不是说……”“这不应被理解为……”“目标不是 X，而是 Y……”“本文并非论证 X，而是论证 Y……”“尽管本研究存在局限……”“当然，这并不能完全涵盖……”。“值得注意的是”“需要澄清的是”“与其说……不如说……”“然而”“尽管如此”“虽然”等表达只在承担实际论证作用时使用。

下表示范改写方向。使用右栏前，逐项确认原稿支持其中的事实、机制和适用判断；示例中的事实不能直接移入用户文章。

| 防御性表达 | 有原稿依据时的直接表达 |
| --- | --- |
| 我们并不认为这些案例能够代表所有情境。 | 这些案例展示了该机制在三种制度环境中如何运作。 |
| 本文无意提供完整的平台治理理论，而是探讨其中一个具体机制。 | 本文揭示了平台治理改变参与方式的一种机制。 |
| 这并不意味着政策设计能够单独决定执行结果。 | 执行结果取决于政策设计与行政能力的相互作用。 |
| 虽然样本有限，无法涵盖所有差异，但仍能提供一些有用的启示。 | 该样本涵盖了与本研究理论问题最相关的差异。 |
| 我们并不认为该模型在所有情况下都更优。 | 需要比较案例并解释差异时，该模型最为适用。 |

## 论文主线

先确定论文的主要贡献：实现了什么新能力、揭示了什么新机制、降低了多少成本，或改善了哪些扩展能力。

摘要、引言、实验和结论围绕主要贡献组织。保留有助于说明主要贡献的其他成果，删去无关铺垫。

## 指标与主张

某项指标落后时，结合论文要解决的问题、比较条件和实际使用需要解释。写清哪个指标提高、哪个指标下降，按各指标的实际结果描述方法表现，保持评价标准一致。

例如，已知相同测试条件下准确率从 90% 降到 89%，延迟从 100 ms 降到 60 ms，直接写：“该方法将延迟从 100 ms 降至 60 ms，准确率为 89%，基线为 90%。”避免把结果笼统改写为“准确率较低，说明该方法仍存在一定局限”。

## 实验的作用

每个实验至少说明一件事：方法是否有效、优势来自哪里、能否排除其他解释，或方法在什么条件下适用。

重复展示的结果，建议合并或精简；与主要结论关系不大的内容，可移到补充材料。会影响核心结论的不利结果必须保留。

缺少实验时，明确哪项主张因此缺少依据。例如，缺少模块 A 的消融实验，就还不能认定性能提升来自 A；应指出这项归因缺口。

## 不利结果

1. 判断结果是否影响核心结论或读者理解，有影响就讨论。
2. 写清在什么条件下、哪个指标出现了什么结果；原因未知时如实说明。
3. 根据证据缩小或撤回主张：只支持部分情况就缩小范围，完全不支持就撤回。
4. 检查是否把某个条件下的问题扩大成方法的普遍缺陷，按证据支持的范围描述。
5. 把限制放在相关章节；摘要或结论省略限定会误导时，在该处保留。

## 审稿意见与正文

模拟审稿时，分清已有证据的问题、仍待核实的问题，以及补做会更好的实验。

修改正文时，处理确实影响结论或读者理解的问题。对审稿人可能提出的疑问，按证据判断是否需要澄清或修复；真正成立的局限才写入正文。

## 中英文表达

中文检查“仅仅做了初步尝试”“只能提供有限参考”“仍有很大提升空间”等习惯性谦辞。直接说做了什么、发现了什么。例如，原稿只支持在两个数据集上完成评估时，写“本文在两个数据集上评估该方法”。

“初步”“可能”“提示”确实符合研究情况时保留。“显著”“全面领先”等判断须有相应证据。

英文同样按证据保留必要的不确定性，删掉重复的保留词。只发现相关关系时，按相关关系表述。例如，观察性分析发现 X 与 Y 相关，可写：

> X is associated with Y in this observational analysis.

避免叠加保留措辞：

> These results may potentially suggest that X could possibly be associated with Y.

“may”“suggests”“under these conditions”是否保留，取决于证据和句子含义。

## 定稿检查

- 逐句确认是否提供信息、说明范围或帮助论证；删改只为防备质疑的句子。
- 删除不必要的免责声明、重复的“本文并不是说”、叠加的保留词和没有信息增量的自我否定。
- 检查摘要、段首、贡献段与结论是否堆放限制、先强调不足、反复澄清或主动贬低贡献。
- 直接交代研究内容和范围，删除不必要的“不研究什么”、对比、转折与让步。
- 收回或缩小证据撑不住的结论，保留影响准确性和使用方式的限定。
- 确认摘要、引言、实验与结论围绕主要贡献，影响核心结论的不利结果得到保留和讨论。
- 核对示例及改写中的事实依据，尤其是“三种制度环境”“最相关的差异”“最为适用”等具体判断；数据、机制、因果关系和优势均须来自原稿或已核实证据。
