# 本地上下文资料路由

`~/.config/akira/` 保存 Akira 的长期个人上下文；它是运行时资料，不属于 Lattice 的静态配置源码。仅在 Core 已判定当前任务确实需要这些资料时进入该目录，并按资料域最小化读取。

## 资料域

- `profile.yaml`：基础资料。身份、联系方式、默认所在地，以及报名等场景可复用的稳定默认值。
- `academic.yaml`：学术资料。教育背景、研究方向、学术会议、学术报告、论文与其他学术履历。学术会议报名、学术简历、讲者简介、科研合作介绍等任务优先读取这里。
- `projects.yaml`：项目资料。产品、开发、比赛和其他项目经历；按具体任务主题选择相关项目，不把项目经历机械并入基础资料或学术资料。
- `system.yaml`：系统资料。本机开发环境、服务部署、端口、反向代理及其他跨项目系统约定。
- `snippets.md`：派生文案缓存。仅用于复用已有表达；事实冲突时以对应 YAML 资料域为准。

## 读取原则

先根据任务判断需要哪个资料域，再只读取对应文件；跨域任务才组合读取。新的长期事实写入其权威资料域，避免在多个文件重复维护同一事实。
